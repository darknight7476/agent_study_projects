# 本周总结

1. 同步和异步的区别是什么？

   同步是阻塞式顺序串行完成任务，异步通过协程遇到需要等待的任务先交出控制权继续往下执行，除非明确要求等待再把结果传回来

2. 什么是协程？

   协程是被async修饰的函数，可以暂停、恢复的函数

3. 什么是事件循环？

   负责调度不同的协程决定哪个协程运行

4. `async` 和 `await` 分别起什么作用？

   async声明协程函数；await挂起当前协程等待可等待对象完成

5. `asyncio.run()` 有什么作用？

   异步程序入口，负责创建新的事件循环、把主协程包装为Task、结束后清理

6. `asyncio.create_task()` 和 `asyncio.gather()` 有什么区别？

   create_task()把协程包装为Task直接丢给事件循环，主协程继续工作不等待，同时存在弱引用陷阱；gather批量执行协程阻塞主协程等待结果

7. 为什么调用大模型 API 适合异步？

   因为网络之间需要协议交换等不需要cpu的等待时间长的I/O密集任务，通过异步可以同时处理多个请求，提高利用率

8. Semaphore 解决了什么问题？

   控制了同时进行的任务数量上限，防止资源占满、并发过载

9. asyncio.Lock 和 Semaphore 有什么区别？

   Lock控制的是协程之间的互斥保证同时只能由一个协程运行，是Semaphore(1)的特例

10. 如何设置请求超时？

    使用wait_for

11. 如何处理部分任务失败？

    使用gather(**`return_exceptions=True`**)、使用try/except

12. 并发数量是不是越大越好？

    不是，过大会带来服务端限流、本地资源耗尽、调度开销增加、超时和重试、延迟增加
